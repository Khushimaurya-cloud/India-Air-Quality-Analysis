
# India Air Quality Analysis (2022–2026)

## Project Overview
This project analyzes air quality data across 50 Indian cities from 2022 to 2026 using Python, Pandas, Matplotlib, and Streamlit.

The goal is to understand air pollution patterns, compare AQI levels across cities, and identify trends in major pollutants.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Streamlit
- Git & GitHub

## Dataset Information
- Total Records: 77,400
- Total Cities: 50
- Time Period: August 2022 – October 2026
- Total Columns: 19

## Key Analysis
- Year-wise Average AQI
- Top 10 Most Polluted Cities
- AQI Category Distribution
- Monthly AQI Trends
- PM2.5 vs PM10 Comparison
- Mumbai vs Delhi vs Pune Comparison

## Dashboard Features
- Interactive dashboard using Streamlit
- Year and city filters
- AQI summary metrics
- Interactive data visualizations
- Dataset overview

## How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/Khushimaurya-cloud/India-Air-Quality-Analysis.git
   ```

2. Open the project folder:
   ```bash
   cd India-Air-Quality-Analysis
   ```

3. Install required libraries:
   ```bash
   pip install pandas matplotlib streamlit
   ```

4. Run the dashboard:
   ```bash
   streamlit run app.py
   ```

## Key Insights
- Delhi has the highest average AQI among the analyzed cities.
- AQI levels show an increasing trend from 2022 to 2025 in this dataset.
- Moderate is the most frequently observed AQI category.
- Average PM10 levels are higher than average PM2.5 levels in this dataset.

## Project Files
- `air_quality_analysis.py` – Python data analysis
- `air_quality_daily.csv` – Air quality dataset
